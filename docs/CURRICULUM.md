# Curriculum

The curriculum is organized by communicative capability + grammar + vocabulary + automaticity, not grammar chapters alone.

## Daily loop
Input → Notice → Understand → Retrieve → Produce → Feedback → Correct → Repeat later → Use in real context.

## Typical day
- Retrieval warm-up
- Vocabulary & chunks
- Grammar in context
- Listening
- Speaking
- Reading
- Writing
- Review
- Exit check
- Real-world mission

## First 14-day block
- Days 1–3: core sentence system and Present Simple
- Days 4–5: negatives and questions
- Days 6–7: routine/frequency + Week 1 integration
- Days 8–10: Past Simple automaticity
- Days 11–12: future plans and arrangements
- Day 13: past/present/future integration
- Day 14: productive checkpoint and baseline retest

## Content ratio
Aim for roughly 70–85% comprehensible material and 15–30% challenge. Reduce difficulty after repeated performance below about 65–70%; accelerate after sustained 90–95% mastery.
