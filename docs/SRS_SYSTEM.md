# SRS System

The review scheduler uses correctness, confidence, interval history and optional response speed.

## Recall directions
- Thai → English
- English → meaning
- Fill blank
- Complete sentence
- Correct mistake
- Speak sentence
- Create original example
- Use in context

## Scheduling
Failed recall resets the interval and increases lapse count. Strong recall expands the interval according to ease. A much slower-than-usual response can shorten the next interval.

## Mastery
Recognition alone does not make an item mastered. Production and repeated successful retrieval are required.
