# Speaking System

Speaking has the highest priority.

## Ladder
1. Word / short chunk
2. Complete sentence
3. Two connected sentences
4. 20–30 second guided answer
5. 45–60 second answer
6. 90 second answer
7. 2–3 minute structured response
8. 3–5 minute spontaneous response
9. C1 discussion, debate and presentation

## Drill families
Repeat, shadow, substitution, transformation, rapid response, sentence expansion, scenario description, guided speaking and free speaking.

## Feedback mode
- Fluency task: learner finishes; then correct 1–3 high-impact issues.
- Accuracy task: immediate correction.
- Accent is not punished. Intelligibility is the goal.

## Browser support
MediaRecorder is used for local recording/playback where available. Speech-to-text can later be added behind an adapter.
