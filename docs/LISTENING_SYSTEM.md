# Listening System

All core listening material is original.

## Four-pass sequence
1. First listen without transcript — gist
2. Second listen — details
3. Third listen with transcript — reductions, linking, stress and contractions
4. Final listen without transcript

## Speed
Browser Speech Synthesis supports adjustable rates. Slow speed is scaffolding, not a permanent mode.

## Topics
Daily life, university, programming, IT, AI, software development, gaming, travel, workplace, science, society, business and technology.
