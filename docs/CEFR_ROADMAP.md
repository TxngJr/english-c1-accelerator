# CEFR Roadmap

## Stage 1 — Foundation Rebuild
A1+ → strong A2. Automate basic sentence construction, present/past/future, questions, negatives, core vocabulary and short conversation.

## Stage 2 — Functional Independence
A2 → B1. Extend conversation, project explanation, travel/work situations, storytelling, opinions, clarification and 1–3 minute presentations.

## Stage 3 — Independent Advanced User
B1 → B2. Natural-speed listening, technical discussions, argumentation, documentation reading, professional writing, summarization and 3–5 minute spontaneous speaking.

## Stage 4 — C1 Advanced Proficiency
B2 → C1. Nuance, stance, synthesis, implicit meaning, multiple accents, professional presentation, debate, analytical writing, register and reformulation.

## Rule
Never promote on vocabulary/MCQ performance alone. Every readiness gate includes productive skills.
